# Seeing while passing

Extend the existing measured-reading workshop into the specification's stated
purpose: chests should open so people passing through can see the equipment.
Use the actual contrast between front and both side walls, not an invented
ancient inspection game. Keep the source's requirement and the model's optical
result as two separate observations.

## Design decision

Preserve Syngraphe's measuring-sheet identity. Paper `#f6f0e4`, ground
`#eee7d8`, ink `#302a22`, correction `#862e24`, visible ray `#4d5d30`, viewer
`#244b75`. Noto Serif remains the single local typeface. A large top-down drawing
is the primary interface; its moving viewer and stopped sightlines carry the
interest. Controls use ordinary words and native sliders/selects. No animation,
score, timer, ornamental temple, or simulated historical official.

```text
Syngraphe                 Measurements | Seeing | Greek | Keep

See the stores.            A front opens here. Both sides there.

+------------------------------------+  Wall chest: [front     ]
| wall          [wall chest]         |  Pillar chest: [front   ]
|                                    |  [Use the stated faces]
|               [pillar chest]       |
|                   # pillar         |  What is visible here?
|          / stopped ray             |  What agrees with the words?
| <-------o viewer----------------->  |
+------------------------------------+
[back] ------- position ------- [forward]

Read the front / both / passing phrases beside whole printed pages
Keep the settings, station table, SVG and illustrated source reading
```

On a phone the drawing precedes controls and the textual result. An enlarge
control preserves legible drawing labels with keyboard panning. All visibility
results and source comparisons also appear outside SVG. The notable element
is an operable sightline drawing; the rest stays quiet. The existing palette
resembles a common editorial default, but changing this room's branding would
weaken continuity. Its actual architectural operation earns the visual identity.

## Scope

One isolated support, two illustrative square chests, one sample point in each,
and 41 discrete viewer stations. Walls, base support breadth and passage width
reuse the previous room's schematic cross-width account. Chest dimensions,
longitudinal placement, sample points, observer location and height-free rays
are modern choices. Neighbouring bays, vertical geometry, people, stored objects,
doors, grilles, lighting, refraction and hinged panels are omitted. A closed face
is an opaque line; an open face is removed. Touching a closed corner blocks.

There is deliberately no claim that seeing two sample points validates the
source's demand to see all equipment. In particular, front openings on both
chests can expose both samples along this path while contradicting the pillar
clause. The model must preserve this resistant case rather than force the
source prescription to be the unique optical solution.
